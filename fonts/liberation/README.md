# Liberation fonts: substitutes for the PDF standard 14

Folium (`docs/spec/folium.md` D7) draws text in a PDF's non-embedded
standard fonts with these, because they are metric-compatible: Liberation
Sans has Helvetica's (Arial's) advance widths, Liberation Serif has Times',
Liberation Mono has Courier's. Text placed by the PDF's widths therefore
lands where the author's reader put it.
